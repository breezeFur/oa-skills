# 根据应用 Tag 查询应用 ID

## 接口信息

| 项目 | 值 |
|---|---|
| 接口 URL | `/api/bs/ebuilder/app/tags/getAppIds` |
| 请求方式 | `GET` |
| 风险等级 | L1，只读 |
| 幂等性 | 是 |

使用 `weaver-e10-login` 建立的已认证会话发送请求。不要在 URL 中添加域名占位符、`access_token`、`ETEAMSID` 或其他认证参数。

## 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 | 校验规则 |
|---|---|---|---|---|---|
| `tag` | Query | String | 是 | 应用标签 | 非空；按配置原值等值查询，不自动改写 |

## 请求示例

```http
GET /api/bs/ebuilder/app/tags/getAppIds?tag=budget-center-app
```

参数必须进行 URL 编码。示例 Tag 仅用于说明请求格式，实际调用必须使用用户或业务配置提供的真实值。

## 响应结构

```json
{
  "code": 200,
  "msg": "接口返回成功",
  "status": true,
  "data": ["1294962588704817153"],
  "fail": false
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | Integer | 业务状态码，`200` 表示查询正常处理 |
| `status` | Boolean | 外层处理状态 |
| `data` | Array<String(Long)> | 匹配的应用 ID；无匹配时为空数组 |
| `msg` | String | 提示或失败原因 |
| `fail` | Boolean | 是否失败；部分基线可能不返回 |

Long ID 通常序列化为字符串。即使某环境返回 JSON 数字，也立即转换为字符串，禁止使用 JavaScript Number 保存大整数 ID。

## 结果示例

单个匹配：

```json
{
  "code": 200,
  "status": true,
  "msg": "接口返回成功",
  "data": ["1294962588704817153"],
  "fail": false
}
```

多个匹配：

```json
{
  "code": 200,
  "status": true,
  "msg": "接口返回成功",
  "data": ["1294962588704817153", "1296755578588971008"],
  "fail": false
}
```

无匹配：

```json
{
  "code": 200,
  "status": true,
  "msg": "接口返回成功",
  "data": [],
  "fail": false
}
```

## 成功判定

同时满足以下条件才进入结果数量处理：

1. HTTP 请求成功。
2. `code == 200`。
3. `status == true`。
4. `data` 是数组。

空数组表示当前租户没有匹配应用，不是系统错误。

## 错误码与失败结果

| 错误码/结果 | 场景 | 可重试 | 处理方式 |
|---|---|---|---|
| `code=200, data=[]` | 无匹配应用 | 否 | 报告未找到，核对 Tag 和应用安装状态 |
| `code=80005` | 部分基线对空 Tag 返回参数异常 | 否 | 补充真实应用 Tag 后再调用 |
| `HTTP 401` | 会话无效或过期 | 否 | 使用 `weaver-e10-login` 重新建立会话 |
| `HTTP 403` | 当前用户无读取权限 | 否 | 确认当前账号与租户权限 |
| `status=false` | 业务处理失败 | 条件可重试 | 读取脱敏 `code` 和 `msg`，参数或权限错误不重试 |
| `HTTP 5xx` 或超时 | 服务或网络异常 | 是，有限重试 | 保持环境和 Tag 不变，最多有限重试 |

## AI 处理规则

1. 返回 0 条时停止后续表单查询，并明确报告未找到。
2. 返回 1 条时将该值按字符串作为 `appId`。
3. 返回多条时展示全部 ID。只有用户明确指定 ID 或要求全部处理时才继续。
4. 不根据数组位置选择“最新”应用；接口没有返回可用于判断导入时间的字段。
5. 不猜测其他 Tag，不自动切换租户，不使用 SQL 兜底。
