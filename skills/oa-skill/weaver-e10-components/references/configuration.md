# 用户开放配置

以下是按组件用途选择的设计候选项，不是平台已实现能力清单，也不要求每个组件开放所有项。只开放能在当前实现中生效的配置。

## 通用配置

| 分组 | 用户配置 | 设计要点 |
|---|---|---|
| 内容 | 标题、说明、单位、空态文字 | 中文标签；清楚区分隐藏、留空和默认值 |
| 尺寸 | 宽度、高度、内边距 | 宽度默认跟随容器；数值明确像素或百分比；不要覆盖设计器拖拽尺寸 |
| 外观 | 主题色、背景色、标题/内容字号、圆角、边框 | 校验颜色和有限数值；默认值形成一致外观；样式限制在实例根节点 |
| 数据 | 数据来源、数据集编号、字段映射、固定条件、刷新方式 | 查询真实返回字段；需要特殊后端协议时明确契约；换绑定同步更新缓存键 |
| 联动 | 联动组、接收筛选项、触发事件 | 区分页面编辑者配置与运行用户筛选；没有监听者的事件不算实现 |
| 明细 | 点击开关、目标页面、目标应用、打开方式、参数映射 | 查询真实目标；按当前平台已验证方式执行；携带当前筛选范围 |

业务必填字段不能凭空默认成某个历史数据集。允许无绑定时展示“请配置数据来源”，阻止错误请求，并保留其他外观编辑能力。

## 按组件类型选择

| 组件 | 推荐开放项 | 关键验证 |
|---|---|---|
| 指标卡 | 主值数据集/字段、单位、小数位、辅助指标、阈值/告警样式、数字点击明细 | 换字段后数字变化；零值显示；缺失值与零不同；多数字分别绑定 |
| 图表 | 图形类型、分类字段、系列字段/名称/颜色、单位、图例、数据标签、排序、最多条数、图形高度 | 类型选择只列实际实现项；排序/截断一致；点击参数取实际分类值 |
| 表格 | 数据集、显示列/顺序/标题/宽度/格式、分页大小、筛选项、导出开关、明细链接 | 显示列真实存在；查询/翻页/导出使用一致条件；隐藏列与权限是不同机制 |
| 期间筛选 | 初始期间策略、允许日期范围、快捷项、联动组、自动查询或确认按钮 | 初始期间按运行日期计算；起止有效；只影响所属联动组 |
| 环形占比 | 分类/数值字段、颜色、中心文字、百分比精度、图例、零总量显示 | 明确分母；总量为零不产生 NaN；字段缺失给错误提示 |
| 比例条 | 分类/值字段、分母模式、排序、最多条数、颜色、标签、单位 | 百分比与原始值区分；分母模式中文可理解；无值不伪装为正常结果 |

后端不支持的排序、筛选、导出不能只在面板放开关。需要补齐接口时按当前任务范围处理，未实现项留在说明中。

## 配置契约模板

在组件交付资料中维护一张表：

| 中文名称 | key | 输入方式/类型 | 默认值与留空含义 | 校验 | 生效位置 |
|---|---|---|---|---|---|
| 标题 | title | 文本/string | 使用组件默认标题 | 纯文本 | Design/View 标题区 |
| 卡片宽度 | cardWidth | 数值/number 或已验证文本输入 | 留空跟随容器 | 有限正数，单位 px | 实例根节点 |
| 数值字段 | bindingField | 字段选择或文本/string | 留空提示未绑定 | 必须属于当前数据集 | 数据映射 |

这张表描述逻辑类型，不宣称存在对应平台控件。为当前版本实测后再填写控件名。

归一化只为缺失值设置默认；非法输入应说明具体字段。JSON 除语法外还需验证对象/数组形状、必填字段、枚举、字段是否存在及重复列。数值禁止 NaN、Infinity；配置不执行 eval 或任意脚本。

复杂配置优先提供可理解的编辑方式。若使用 JSON 高级配置，给最小样例，例如：

```json
[{"name":"amount","label":"金额","width":140}]
```

`name` 必须换成真实返回字段。说明单位、顺序与留空行为；不要让普通用户从完整页面 JSON 中找配置。

## 有效性验收

- 面板有字段，运行代码有消费者，保存回读值一致。
- 改标题/颜色/尺寸可见；容器拖拽宽高不被旧样式锁死。
- 换数据集及字段生效，非法字段有可理解提示；旧请求不覆盖新绑定。
- 保存后刷新设计器，运行页重新打开仍保留；复制实例后独立编辑。
- 修改已有组件后，旧实例配置兼容；未编辑字段和其他页面实例保持原值。
- 关闭导出/点击等功能，按钮和事件均按配置生效；权限继续由服务端校验。
